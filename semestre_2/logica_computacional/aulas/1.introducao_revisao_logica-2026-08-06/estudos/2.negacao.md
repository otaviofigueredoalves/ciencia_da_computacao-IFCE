# Negação
- Operador unário/função que só precisa de 1 fórmula atômica para funcionar

## Tabela verdade
- Existe porque a lógica proposicional é bivalente, e ela só aceita dois valores: Verdadeiro ou Falso. Como o número de opções é limitado conseguimos representar bem através da tabela

## De re, De dicto

**DE RE:**
Q = "O maior número primo é par"
NÃO Q = "(O maior número primo) NÃO é par"

**DE DICTO:**
Q = "NÃO é o caso que (o maior número primo é par)


São proposições diferentes pois
De Re está se comprometendo com "o maior número primo" assumindo-o como verdade. Só que é FALSO pois não existe "maior número primo"

Já o De Dicto começa negando toda a proposição, ou seja "não é o caso que"(proposição)

- ¬(P ∧ Q) -> O Não está do lado de fora. Ele nega a união inteira (De Dicto).
- ¬P ∧ Q -> O Não é unário e tem a maior prioridade. Ele afeta APENAS o P (De Re). O Q continua normal.

- **DICA:** use parênteses para separar bem as operações que quer negar
```php
// DE DICTO (O jeito certo e seguro)
if ( ! ($usuario->temSaldo() && $usuario->isAtivo()) ) {
    // "Não é o caso que (o usuário tem saldo E está ativo)"
    bloquearCompra();
}
```
